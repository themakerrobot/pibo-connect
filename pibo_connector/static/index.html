로봇 찾기
교실 네트워크
교실에 켜진 로봇을 찾아요. 5초쯤 걸려요.
출석 확인
출석부 (우리 반 로봇 번호)
로봇 가슴의 8자리 번호를 적어요. 띄어쓰기는 아무렇게나.
로봇 목록

아직 로봇이 없어요.
[로봇 찾기]를 눌러 보세요.
코드
파일 위치
고른 로봇 모두에서 이 파일을 그대로 실행해요. 위 코드 창은 쓰지 않아요.
Ctrl+Enter 실행
알아두세요
⚠ 실행하면 로봇의 다른 기능(도구·인식·AI 대화)이 잠깐 멈춰요. AI 대화는 코드에서 Dialog.start_llm 을 먼저 불러요. 로봇 코딩 화면(IDE)에도 같은 결과가 보이고, 거기서 실행을 누르면 여기 코드는 멈춰요.
다 같이 시작: 준비를 먼저 끝내 놓고 신호 한 번에 모두 움직여요. 코드에 # --- GO --- 줄을 넣으면 위는 준비, 아래는 동작이에요. 공유기가 신호를 막으면 [timeout]으로 끝나요. 그럴 땐 [실행!]을 쓰세요.
결과
실행하면 로봇마다 마지막 줄이 여기 나와요. 누르면 전체가 펼쳐져요.
로봇 종류 구분 설정
로봇 버전 이름에 이 글자가 있으면 그 종류로 봐요. 긴 글자부터 확인해요 — pibrain이 pibo보다 먼저예요.
로봇 안의 파일
고른 로봇 모두 같은 자리에 이 파일이 있어야 해요. 없는 로봇은 [missing]이라고 나와요.
